# The Chronicles of Komon (Sanctum of Nueng) ⚔️✨

An interactive 3D fantasy web animation experience guided by **Jenis**, a celestial floating spirit orb that narrates the story, passions, daily rituals, and inspirations of **Nueng (Komon)**.

![Sanctum Preview](https://img.shields.io/badge/Theme-Fantasy%20Sanctum-f5d061?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)

---

## 🌟 Key Features

- **Interactive Fantasy Gate:** 3D animated opening sequence with ancient rotating runes, unsealed only upon player interaction.
- **Celestial Companion (Jenis):** Floating glowing orb with dynamic astral rings and reactive voice wave animations.
- **AI Voice Narration:** Smooth, expressive voice acting paired with English dialogue and Thai CC subtitles (with typewriter effect).
- **Dynamic Fantasy Backdrops:** Real-time visual cards illustrating Nueng's engineering prowess, music & car passions, daily routine, and Amway journey.
- **Procedural Sound FX Engine:** Web Audio API generating bass rumbles, portal swooshes, and chime magic.
- **Instant Reset:** Clean state reset button restoring the sealed gate.

---

## 🚀 How to Run Locally

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, or Safari). No dependencies or build steps required!

```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git

# Navigate to the folder
cd <your-repo-name>

# Open index.html directly or with Live Server
```
